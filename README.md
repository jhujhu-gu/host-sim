# 關主模擬器｜品牌色彩挑戰

熊本北高中來訪（12/17）「品牌色彩挑戰」關主與小幫手的英文口說練習網頁。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁入口 |
| `app.js` | 遊戲流程、比對、報告 |
| `data.js` | **句子與題卡資料**，想改句子就改這個檔案 |
| `style.css` | 畫面樣式 |
| `assets/` | 角色、道具、背景圖片 |

## 放上 GitHub Pages

1. 登入 GitHub，按右上角「+」→「New repository」，取名例如 `host-sim`，選 **Public**，按「Create repository」。
2. 在新 repo 頁面按「uploading an existing file」，把**解壓縮後的所有檔案與 `assets` 資料夾**一起拖進去，按「Commit changes」。
3. 到 repo 的「Settings」→ 左側「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按「Save」。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/host-sim/`，用手機開就能練習。

## 小提醒

- 語音作答：iPhone 請用 **Safari**，Android 請用 **Chrome**；第一次會詢問麥克風權限，請按「允許」。
- 練習紀錄、貼紙存在手機瀏覽器裡；換手機或清除瀏覽器資料會不見。
- 修改 `data.js` 後重新上傳覆蓋即可，句子的 `en` 是英文、`zh` 是中文、`sit` 是情境說明。
